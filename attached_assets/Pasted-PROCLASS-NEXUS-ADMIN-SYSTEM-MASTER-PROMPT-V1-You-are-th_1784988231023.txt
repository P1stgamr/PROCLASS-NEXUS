- Create Membership Plans.

- Send Notifications.

- Manage Banners.
- Manage AI Features.
- View Analytics.
- View Logs.
- View Reports.
- Manage Platform Settings.

No permission restrictions.

---

2. Basic Admin

Basic Admin is limited.

Basic Admin CAN:

- Manage Courses.
- Manage Subjects.
- Manage Chapters.
- Upload PDF.
- Upload Videos.
- Create Practice Questions.
- Create Exams.
- Edit Exams.
- Publish Exams.
- Manage Student Results.
- Approve Submitted Tasks.
- Create Announcements.

Basic Admin CANNOT:

- Create another Admin.
- Delete Super Admin.
- Change Membership Pricing.
- Access Wallet Settings.
- Access Payment Settings.
- Access Platform Settings.
- Access Security Settings.
- Access Firebase Configuration.
